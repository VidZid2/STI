## 📖 What is this?

This is **STI eLMS** — a modern, redesigned version of the STI College Learning Management System (LMS). I built this as my **Case Study project** during my first year at STI College.

The goal was simple: take the existing STI eLMS platform and make it look and feel way better — with a clean, modern design that actually feels good to use. Think smooth animations, dark mode, a beautiful dashboard, and tools that students would actually enjoy using.

This is **not** the official STI eLMS. This is my personal redesign of it for academic purposes.

---

## ✨ What's Inside

Here's what I built into this project:

- **🏠 Student Dashboard** — A clean home page with quick stats, course progress, and activity tracking
- **📚 Course Pages** — Browse and view your enrolled courses with a modern card layout
- **🛠️ Study Tools** — Built-in tools like Grammar Checker, Paraphraser, Citation Generator, Plagiarism Checker, and more
- **📊 Goals & Paths** — Set study goals and track your learning paths
- **👥 Group Chat** — A group messaging page for students
- **🔔 Notifications & Inbox** — Real-time notifications and mail system with dropdown menus
- **🌙 Dark Mode** — Full dark mode support across the entire app
- **📱 Mobile Responsive** — Works on phones, tablets, and desktops
- **🎨 Smooth Animations** — Micro-animations and transitions powered by Framer Motion
- **👨‍🏫 Teacher Dashboard** — A separate dashboard for teachers to manage students and grades
- **🔐 Admin Dashboard** — Admin panel for managing the whole system

## 🛠️ Built With

| Tech | What it does |
|------|-------------|
| **React 19** | The main framework for building the UI |
| **TypeScript** | Adds type safety so there are less bugs |
| **Vite** | Super fast build tool and dev server |
| **Framer Motion** | Handles all the smooth animations |
| **Tailwind CSS** | Utility-first CSS for quick styling |
| **Supabase** | Backend database and authentication |
| **IndexedDB (Dexie)** | Local storage for offline data |

## 🚀 How to Run (For My Own Use)

```bash
# 1. Clone the repo
git clone https://github.com/VidZid2/STI.git

# 2. Go into the folder
cd STI

# 3. Install all the packages
npm install

# 4. Start the dev server
npm run dev
```

Then open your browser and go to `http://localhost:5173`
