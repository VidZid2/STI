## 🎯 About

**STI eLMS** is a ground-up redesign of the STI College Learning Management System, reimagined with modern SaaS-grade aesthetics and premium UX patterns. This isn't just a reskin — it's a full rethink of how a student LMS should look, feel, and function.

Built as a **first-year case study project**, it demonstrates what a next-gen educational platform could look like with today's best web technologies.

> [!NOTE]
> This is **not** the official STI eLMS. This is a personal academic redesign for case study purposes.

## 📁 Project Architecture

```
src/
├── components/
│   ├── shared/          # Reusable components (ErrorBoundary, etc.)
│   └── ui/              # Design system primitives
│       ├── dropdowns/   # QuickSettings, Help, Streak dropdowns
│       ├── modals/      # Getting Started, FAQs, Contact Support
│       ├── effects/     # Visual effects & particles
│       └── misc/        # Toggle buttons, switches, utilities
├── pages/
│   └── studentdashboard/
│       ├── components/  # Dashboard-specific components
│       ├── content/     # Page content (Home, Goals, Courses, etc.)
│       └── widgets/     # Sidebar widgets (Todo, Calendar, Weather...)
├── services/            # API & data services
├── styles/              # Global CSS & dashboard styles
└── hooks/               # Custom React hooks
```

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/VidZid2/STI.git

# Navigate to the project
cd STI

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open **http://localhost:5173** in your browser.
